Como funciona

Este site é um arquivo estático (sem servidor próprio). Suas edições aqui ficam salvas automaticamente neste navegador, então clicando em "Ver site" você já visualiza o resultado. Para a mudança valer para todos os visitantes, clique em "Baixar config.js atualizado" e substitua o arquivo config.js no seu servidor/hospedagem pelo que foi baixado (mesmo nome, mesmo lugar).
