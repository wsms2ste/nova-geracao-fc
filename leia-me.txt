ESCOLINHA NOVA GERAÇÃO F.C. — GUIA RÁPIDO DO SITE
====================================================

ARQUIVOS DO SITE
-----------------
index.html   -> a página que os visitantes veem
admin.html   -> o painel administrativo (edição de tudo)
config.js    -> onde ficam guardados preços, links, textos e fotos
assets/      -> imagens (escudo, uniformes)

Os quatro precisam ficar SEMPRE juntos, na mesma pasta, no seu servidor
de hospedagem (Hostinger, Hostgator, GitHub Pages, etc). Não renomeie
nenhum arquivo.


COMO PUBLICAR
--------------
1. Envie a pasta inteira (index.html, admin.html, config.js e a pasta
   assets) para o servidor do seu site, do jeito que está.
2. O endereço do site público será o de sempre (ex: novageracao.com.br).
3. O painel fica em: novageracao.com.br/admin.html
   Senha inicial: novageracao2026  (troque assim que entrar!)


COMO EDITAR PREÇOS, LINKS E FOTOS
-----------------------------------
1. Acesse .../admin.html e faça login.
2. Edite o que quiser: WhatsApp, Instagram, preços da loja, fotos dos
   produtos, link de transmissão ao vivo, jogos da semana, unidades,
   ofertas e a senha do painel.
3. Toda alteração já fica salva automaticamente NESTE NAVEGADOR — clique
   em "Ver site" para conferir como ficou.
4. Para a alteração valer para TODOS OS VISITANTES (não só no seu
   navegador), clique em "Baixar config.js atualizado". Isso baixa um
   novo arquivo config.js pronto.
5. Envie esse config.js baixado para o servidor, substituindo o
   config.js antigo (mesmo nome, mesma pasta). Pronto — o site
   atualiza para todo mundo.

Isso é assim porque o site é um site simples e leve, sem mensalidade de
banco de dados — o que deixa ele rápido e barato de manter. Se no futuro
vocês quiserem que a equipe edite o site de qualquer computador e a
mudança apareça na hora pra todo mundo (sem precisar reenviar arquivo),
dá pra evoluir o painel para salvar direto num banco de dados online.
É só pedir.

SEGURANÇA DO PAINEL
-----------------------------
A senha protege o acesso ao painel de edição, mas por ser um site sem
servidor próprio, não é o mesmo nível de segurança de um sistema
bancário — é o suficiente para impedir curiosos, mas não compartilhe a
senha e troque-a periodicamente pelo próprio painel (seção Segurança).
